# 版本化迁移交付（2026-11-13）

依据 ADR-017 / Frozen v1.5 修订 1 实现。当前登记版本为 1 / baseline_v1_5；账本包含版本、名称、SHA-256 与应用时间。内嵌基线来自本项目权威 DDL，不来自 references；测试验证二者及初始化登记摘要一致，SQL 固定 LF 换行。

## 使用

在 backend 执行 `go run ./cmd/migrator schema status` 查看账本，`schema check` 检查账本与视图，`schema up` 执行迁移。DATABASE_URL 支持 URI 或 kv conninfo。status/check 只读；up 默认仅允许回环地址、显式端口、yreader_test 或 yreader_a1_iso_*，无绕过选项。Makefile migrate 在原 Python 门禁后调用相同 up 命令，不再直接重放 SQL。

空库应用内嵌基线；没有账本的旧库执行幂等基线补齐并登记。已有正确记录时不重放 DDL；漂移、未知版本拒绝。整次 up 在事务咨询锁内重新读取账本，DDL 和登记同事务，错误整体回滚。up 结束后另检查视图；已有账本但人为破坏结构不会被静默修复。启动/readyz 只读校验，绝不自动 up。

新实例通过 docs/schema.sql 在初始化事务内登记同一校验和；两条 CI 流水线在初始化后执行 schema check，race 流水线还运行隔离升级测试。CI 首次远程结果仍未取得。未来新增版本须增加独立迁移实现并修订契约，不能修改已经发布的基线校验和来掩盖漂移。
