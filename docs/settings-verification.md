# 账户阅读设置交付与验证

日期：2026-11-12。按 Frozen v1.5 / API 1.0.0 既有 Settings 扁平键值与浅合并语义实现。

## 行为

- 设置页采用 Element Plus，提供四种主题、14–32px 整数字号及实时外观预览；核心阅读器继续采用原生控件。
- 使用 reader.theme 和 reader.font_size。加载时校验值，未知主题、非整数字号及越界值回退至羊皮纸 / 20px；写入只发送变更键，恢复默认仅删除这两个键，保留其他用户设置。
- 刷新和重新登录后从服务端恢复；IndexedDB 保存每个账户的设置镜像和未同步键。离线修改会保留，可在原会话刷新后恢复，再手动或联网重试。设置缓存属于第 3 版增量表，不删除章节或进度。
- 快速连续修改串行发送 PATCH，旧响应不会替换较新的未同步值。切换账户、退出或卸载后旧响应失效；退出清理该账户设置缓存。
- 修复共用请求层：旧账户请求收到 401 后，如果会话已换成另一账户，不再用新账户凭据重试。刷新令牌途中切换账户也受相同身份检查约束。
- 阅读器手动调整外观时先捕获字符位置，再重排和恢复；不会因字号变化将位置保存成另一段。

## 验证

- strict TypeScript 通过；31 项 Vitest 单测通过。设置新增 7 项，覆盖非法值回退、变更键提交、快速修改、离线刷新重试、账户切换迟到响应、退出清理、默认删除及初次读取失败重试、旧 IndexedDB 升级保留进度。请求层另补 1 项跨账户 401 重试回归。
- Node 22 生产镜像构建通过。最终生产 Nginx 全量 7 项 Playwright 通过（23.0s），包含既有书签、本地阅读与离线、搜索书架、虚拟目录、书源管理与换源。
- 相同最终业务代码在开发 Vite 环境全量 7 项浏览器测试通过（28.1s）。
- 设置场景使用真实隔离后端验证保存、刷新、退出后重新登录、保留未知设置键、恢复默认的取消/确认、阅读器应用设置与字号变化保持字符偏移。
- 仅对设置 API 注入断网，验证待同步设置经页面刷新恢复，再显式重试落库；不将其描述为离线应用壳验证。
- 390px 设置页面无横向溢出，截图已检查，位于 frontend/.test-artifacts/settings-mobile.png。
- 初次浏览器测试对 Element Plus 主题控件的 label 产生双匹配，随后其 readonly 输入被可见选项层遮挡。已改用明确 combobox 角色和受支持的 ArrowDown 操作，不强制点击或增加超时。

## 边界

设置接口没有版本条件，跨端同键以最后完成的写入为准；未实现跨端实时推送。只补齐阅读外观设置，网络策略、用户管理等其他设置仍待实现。

退出会清理本机未同步设置；需要保留离线修改时应先完成同步。离线应用壳仍未实现，首次完全断网加载应用不在本轮承诺范围。缓存写入失败会显示错误，不能保证该设备刷新后的离线恢复。

本轮没有改动后端和冻结契约；10 个冻结文件摘要一致。未访问 references，未触碰现有业务数据库、迁移或发布，未提交、推送或触发远程 CI。后端使用前轮最终镜像，本轮不声称重新执行 Go race。

验收后已移除本轮 yreader-proxyverify 的 4 个容器、专属网络及唯一测试卷；保留本地验证镜像和忽略目录内截图。现有业务服务未停止。
