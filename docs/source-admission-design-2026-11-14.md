# 书源 concurrentRate 与域名组合准入 v1

日期：2026-11-14。状态：本轮实现契约。既有研究、DDL、OpenAPI 43 操作、备份冻结文件均不修改。延续 architecture.md 的数字并发上限与 n/ms 令牌桶语义；现有每次搜索重新创建 limiter 的实现将删除。本轮不部署。

## 输入、身份及更新

从已校验归属的 BookSource 读取数据库 UUID 与 concurrent_rate，不接受客户端另传身份。搜索、目录刷新、正文抓取（含后台缓存）、规则调试均设置不可由 JS 变量覆盖的 Go context；后续解析中的 java HTTP 桥接继承相同 context。命中内容缓存、本地章节及不出网的规则不消耗预算。

JS 桥接失败仍服从既有沙箱包装、字段容错和调试 trace 规则，不为本模块另改解析失败的公开错误码。多实例要全部运行支持源身份的新版本；旧版实例只有域名限制，混合版本不保证完整源并发上限。

去掉首尾空白，空值只执行域名限制；非空规范字符串最多 64 字节，先检查长度再分割，避免巨型斜线串导致大量分配。纯 ASCII 十进制数字 1..256 表示每源同时最多 n 个 HTTP 响应；n/ms 表示容量 n、每 ms 毫秒补 n 个令牌的令牌桶，n 为 1..256，ms 为 1..600000；斜线两侧允许空白，前导零归一。其他非空值拒绝本次出网（既有 502 source_request_failed），不静默取消限流，不改存储原值或公开 DTO。

书源 UUID 对应一个共享策略状态，不把策略串拼入键名绕过预算。策略变化在旧状态仍有效时拒绝新的不匹配快照；数字模式最后响应释放后可立即接受新策略，窗口状态在空闲 TTL 到期后可接受新策略。TTL 为 max(30 秒, 窗口)，最长 10 分钟；更新后可能暂时抓取失败，需等待旧状态空闲过期。已运行请求按读取时快照完成，不能声称配置更新能立即撤销已发请求。删除重建为新 UUID 视为新源，域名预算仍共享。

空值是显式关闭源限制的例外：立即只执行域名限制，不删除已有源状态，也不追踪关闭期间新发请求。重新开启无法追溯关闭期间已发请求，要求调用方排空这些请求后再依赖源并发上限；不能用“运行时切换”宣称无间隙重配置。旧状态仍存在时重新开启也不能重置该状态。

## 原子组合与资源边界

生产共享 Fetcher 在每个应用层 HTTP 尝试前原子检查 hostname 500ms 间隔和书源容量；两者都可用才消耗域名令牌及源令牌/名额。拒绝时不预订未来名额，不消耗另一层预算，允许清除已过期租约。每次最多等待 5 秒，服从更早的调用方截止，不保证 FIFO。重试和每跳重定向重新计费；重定向保留源身份，域名按目标重新计算。Go Transport 内部连接重试仍共享一次预算。

每个成功的受限源请求使用独立随机租约 token；所有源模式均跟踪响应租约，最多 256 个在途响应，防止窗口模式使状态无限增大。数字模式据租约数判断并发，窗口模式另消费令牌。租约 30 秒，无心跳；一次受限请求从准入后到正文读取最多 20 秒，取消、EOF、Close 或截止都会尝试幂等释放。释放使用独立最多 1 秒的清理 context；释放失败保留名额到过期，不盲目补发或删除其他 token。

这是客户端 HTTP 生命周期的容量约束：进程暂停超过租约、远端无视断连继续计算或 Redis 数据丢失时，不能证明远端严格并发数。租约不是可约束第三方站点的 fencing token。未配置 Redis 的状态仅进程内共享；配置 Redis 后故障一律拒绝，不回退内存。

## 存储

Redis 使用同一实例/DB 的 Lua EVAL，原子检查域名键、源 metadata HASH 和 leases ZSET。窗口补充及租约回收采用 Redis TIME，避免应用实例时钟差。键含源 UUID/域名的 SHA-256，版本化前缀；metadata 与租约都有 TTL。此客户端仅支持单 Redis 端点，未提供 Redis Cluster 跨槽路由或一致性保证。类型损坏、缺失 TTL、不合理计数或策略状态拒绝，不返回原始 Redis 错误。

Lua 运行时错误不具有数据库回滚语义；连接中断、OOM 或运行时异常可能已消耗部分预算，结果未知时拒绝出网并尝试按 token 清理租约，域名/窗口预算不退还。这里的“不消费另一层预算”指正常容量拒绝路径，不宣称故障下所有写入都回滚。命令依据：[Redis EVAL](https://redis.io/docs/latest/commands/eval/)、[Redis TIME](https://redis.io/docs/latest/commands/time/)。

内存驱动使用同一互斥锁组合检查，域名最多 4096、源状态最多 4096，每源最多 256 个租约。只回收过期状态，不驱逐活跃预算来腾位置。窗口算法与 Redis 一致。

Redis ACL 除原有缓存命令外，需允许脚本及 TIME、PTTL、TYPE、SET、HGET/HSET、ZCARD/ZADD/ZREM/ZRANGE/ZREMRANGEBYSCORE、PEXPIRE、DEL；权限不足按故障拒绝出网，不声称只保留 GET/SETEX 权限的账号可直接使用。

覆盖解析及非法输入、跨请求共享、两个驱动的双层不消费、并发竞争、不同源隔离、窗口补充、策略变更、租约过期、旧 token 不释放新请求、EOF/Close/取消/超时、重试重定向和 JS 继承。临时真实 Redis 执行脚本并跑 race；服务层回归证明接口与解析行为未破坏。全部测试数据均为合成，不能代替真实书源和故障转移验收。
