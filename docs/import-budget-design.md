# ADR-018：同步导入预算与超时（Frozen v1.5 修订 2）

2026-11-13，先冻结本设计再实现。保持同步导入和 SHA-256 重复文件语义；不增加异步任务、上传续传或自动重试。

LOCAL_IMPORT_TIMEOUT 配置解析及落库阶段的预算，默认 90s，允许 1s–10m 的 Go duration；非法配置拒绝启动。预算从文件接收和格式识别完成后开始，不代表整个上传的总时限，也不能强杀不响应 Context 的计算或驱动。

预算超时返回 504/import_timeout、Retry-After: 10。它表示结果尚未确认，不承诺数据库一定未提交；用户应先刷新书架，必要时重新上传同一文件，依靠既有哈希去重收敛。断开客户端不转成服务端预算超时。Nginx 等待预算调至 660s 以覆盖最大配置，其他代理需自行对齐。

新增错误码与导入 504 响应，不改数据结构或已发布迁移基线。schema.sql 仅在不计入基线摘要的登记注释区域标明无 DDL 变化。测试使用可控服务替身验证真实上下文预算，不依靠导入时长压线；已有性能阈值及同步大书功能回归继续保留。异步大书导入仍为后续独立契约设计。
