# 替换净化规则管理交付（2026-11-13）

沿用 Frozen v1.5 修订 2 的规则接口和数据结构，不新增操作、DDL 或修改已发布迁移基线。

## 行为

设置页新增规则入口。Element Plus 编辑器支持名称、分组、表达式、替换文本、范围、顺序和启停；保存、确认删除、未保存草稿切换确认及路由离开保护。表达式由 Go/RE2 服务端校验，不用 JavaScript RegExp 冒充预检；400/422 保留草稿。空替换文本用于删除匹配内容。超过100条列表仍使用虚拟表格，少量记录缩小高度。

更新使用既有完整 PUT，没有版本条件，并发修改以最后保存为准；不宣称已实现409草稿合并。范围 title 仍可管理，但当前阅读正文仅应用 content/all，不声称补齐标题净化。

保存/启停/删除成功后清理本账户本机正文章节缓存，保留书籍元数据、阅读进度、书签、设置和任务及其他账户缓存。其他已打开页面和设备的正文不会实时推送更新，需联网重新打开；跨页在途预取及其他设备离线副本不承诺即时一致。净化改变字数后应核对阅读位置。

后端缓存原来只验证来源，可能在规则修改后继续返回旧正文。本轮给缓存载荷加入内部规则指纹，包含书源规则和启用的正文用户规则快照；相同快照用于净化及登记。读取和Worker预热均检查指纹，旧载荷没有指纹时回源。缓存键和7天TTL保持不变，无需全库删键。规则同序号按ID稳定决胜；规则查询失败时不复用无法验证的缓存。
