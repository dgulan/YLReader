# 换源重定位专项验证

日期：2026-11-12。范围：DEF-MAP-01，按 Frozen v1.5 既有语义实现，不代表全产品发布验收。

## 行为

- 目标目录为空时返回 422 relocation_failed；先同步目标目录，再预览或提交。
- 精确匹配限定旧索引 ±20，按距离、原始标题相等、较小索引排序；置信度 1。
- 模糊匹配限定 ±100，使用 pg_trgm 的 % 前置谓词及 similarity >= 0.6；按相似度、距离、索引排序，返回实际相似度。阈值使用事务局部设置，避免连接池会话状态影响候选集。
- 无匹配时按新旧整书章节数比例定位并钳制边界，置信度 0.3。
- dry_run 仅计算。提交时活跃源、映射、进度、书籍章节总数及单章覆盖清理处于同一事务；失败整体回滚。
- chapter_ratio 表示章内比例。换源将 char_offset 置零，首次读取目标章真实正文后按 Unicode code point 数计算偏移；不信任目录中估算的 word_count。
- 进度写入和换源都先锁书籍，再更新进度。正文网络抓取位于事务外；延迟偏移写入使用版本条件，期间出现的新进度优先，不被迟到正文覆盖。

## 验证范围

新增数学边界单测及隔离数据库专项：精确同距决胜、模糊匹配、比例回退、预览不写入、空目录、版本递增、旧版本拒绝、Unicode/emoji 偏移、估算字数不可信、正文期间并发更新、失败回滚及覆盖保留。既有换源 API 测试补齐真实目录夹具。

前端 strict TypeScript、17 项单测和生产构建通过。最终后端镜像搭配生产 Nginx 的 5 项浏览器测试全部通过（16.9s），覆盖登录、本地阅读/进度/离线、搜索书架、书源编辑调试删除、换源预览和确认。复跑曾因固定书名复用旧进度导致“开始阅读”定位失败，已将该夹具书名改为每轮唯一并全量复验。上游响应仍使用固定样本，未声称公网书源兼容性或多设备性能验收。

本机原生全量集成曾出现既有导入计时超限；空闲单独复跑耗时 87ms，通过原 600ms 阈值。Linux 全量 race 的一次并发包执行出现沙箱计时超限；调整为包串行后沙箱通过，但既有 TestLocalConcurrentImport 耗时 2.02s 超过 1s 阈值。该轮 176 个顶层测试中 175 通过、1 失败，含子测试 246 通过、1 失败，0 跳过、0 DATA RACE。没有修改耗时阈值。原始日志保留在忽略目录 .toolchain/relocation-race*.jsonl；后续单项复跑结果另列，不将重试描述为整轮通过。

后续同一最终镜像单独复跑 TestLocalConcurrentImport，保留其内部双请求并发、原始 1s 阈值及 race 检测：106.84ms，通过。日志为 .toolchain/relocation-race-import-retry.jsonl。全量测试中的单次计时失败仍保留为环境负载敏感项，不宣称全量一遍通过。

## 边界

旧客户端曾错误保存章内比例，缺少原始正文时无法可靠批量还原。本次只修正新保存行为，不迁移真实用户数据。预览与确认之间可能有另一端写入；前端版本复查属于提示，服务端确认按提交时最新已保存进度定位，不保证与预览完全相同。

冻结的研究、architecture、schema、OpenAPI 共 10 个文件摘要保持不变。未访问 references，未触发远程 CI、提交或发布；未连接现有业务数据库。测试仅使用本轮拥有的隔离 PostgreSQL、Redis、容器及文件卷。

收尾已移除 yreader-proxyverify 项目的 4 个服务容器、专属网络及唯一 storagedata 测试卷，并停止端口 55439 的临时 PostgreSQL。日志和本地验证镜像保留，现有 PostgreSQL 服务未停止。
