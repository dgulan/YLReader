# 同步导入预算交付（2026-11-13）

依据 ADR-018 / Frozen v1.5 修订 2。LOCAL_IMPORT_TIMEOUT 默认 90s，可配置 1s–10m；非法配置在启动连接数据库前拒绝。接收文件及格式识别后创建处理 Context，不将该预算描述为整个上传总时限。Nginx 等待超时由 120s 对齐为 660s。上传上限仍为 100 MiB。

预算耗尽返回 504/import_timeout、Retry-After: 10；即使服务层将取消包装成提交失败，也按实际处理 Context 分类。已知成功仍返回成功；客户端取消不标记为服务端导入预算耗尽。结果未确认时提示先刷新书架，再决定是否重新选择同一文件；不自动重传。哈希去重及原有事务/存储清理逻辑未改。
