## 修复边界

- HTTP 请求体重试只重放可可靠重建的标准内存 reader；不为不可重放 reader 无界缓存，不重复执行不可重放请求体。
- 字符集继续尊重明确 HTTP charset，保留 x/net 对 meta/BOM 的探测；无明确编码且字节非 UTF-8 时才回退 GB18030。不为修复中文覆盖明确的西欧编码声明。
- JSON 解码拒绝多份 JSON、缺失/为 null 的必填数字字段和不可表示的索引；明确区分请求体超限与语法错误，不改生成 DTO 类型。
- 刷新轮换/复用吊销在同一数据库事务内按用户锁串行化，不能只增加一次 UPDATE 而留下“吊销先于新 token 插入”的竞态。客户端刷新增加有界等待，结果未知时不自动重放 refresh token；重登录才重置未知状态。
- 日志仅记录路由模板（未知路径用固定标识），不记录实际路径参数、query、凭据或 panic 值；认证用户 ID 只写已通过认证的上下文。
- JS 标签匹配只折叠 ASCII 标签字符，不能把整个 Unicode 规则转小写后直接用改变长度的字节下标切片。选择器优化保留节点边界；索引排除必须实际过滤。
- CAS 补取消检查，但普通文件阻塞系统调用不能被 contextReader 强制打断；不宣称添加包装后就能立即取消慢 NAS I/O。失败保留目录符合既有保全协议，不能递归删除可能属于其他进程的目录。
- 前端网关回退仅允许 502/503/504，仍验证缓存 owner/书籍版本；401/403/404 与其他业务拒绝不读缓存绕过权限。
- 源编辑器脏草稿使用现有 Element Plus 确认模式；纯只读/未改动不阻断导航。
- 非阻塞离开先确保持久化本机，再让既有进度任务完成；快照和世代检查防止旧确认写入新书。不能取消未确认写入后声称已回滚；若本机失败且没有远端确认，应保留页面并明确提示。
