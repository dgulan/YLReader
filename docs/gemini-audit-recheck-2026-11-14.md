# Gemini 审计逐项复核（2026-11-14）

范围：D:\comments.txt 中各批次发现、风险、最终汇总去重后的 36 组线索。编号按议题而非 Gemini 重复的段内编号排列。报告中“已证实”不等于已复现，本表以当前工作树与新增测试为准。保留此前未提交修改，不访问 references，不部署、提交、推送或合并。

## 逐项结论

| ID | 审计主张 | 复核分类、证据和处理 |
|---|---|---|
| 01 | 幂等重试复用耗尽 body；请求创建错误未分类 | **真实缺陷，已修复**。标准内存 reader 以 GetBody 重建；其他 reader 不重试，不无界缓存。请求构造错误包装 ErrUnsafeURL。模拟 Transport 逐次比对完整 body。 |
| 02 | charset 不处理 meta/BOM、错误 ISO 声明、裸 GBK | **混合结论**。x/net 本来已探测 meta/BOM；明确西欧 charset 不能擅自改 GBK。无声明且非 UTF-8 的裸中文回退缺口**已修复**，原始与解码后均受大小限制。新增 GBK/meta/显式西欧测试。 |
| 03 | AES 方法名/CBC/DES/UUID 缺失，ECB/MD5 不安全 | **兼容能力未完成**。命名方法/CBC/DES 语义尚需冻结独立互操作 profile，不能猜参数后更换既有别名。ECB 是书源协议兼容占位，不是 header 落库方案；header 已用 GCM。本轮补 randomUUID 和严格 padding 检查，保留旧 AES 别名，完整兼容列待办。 |
| 04 | 大小写混合 JS 标签无法解析 | **真实缺陷，已修复**。只折叠 ASCII 标签字节，保留脚本和 Unicode 长度，覆盖中文/İ 前缀。没有采用可能改变字节长度的全串 Unicode ToLower 切片方案。 |
| 05 | @put 无 trace；字段节点反复解析 | **部分修复/性能待办**。有效 @put 子规则透传 recorder，已补测试。直接 NewDocumentFromNode 会丢失“根节点本身可命中”语义，实际让黄金集跌到 88.6%，已撤回该优化；保留正确边界后为 90.9%，没有降低门槛。嵌套 JS/@put 更完整语法需另行设计。 |
| 06 | 宽后缀公开路径、登出忽略畸形 JSON | **防御性缺口及真实错误响应，已修复**。精确公开路径集合，畸形非空 JSON 返回 400。现有路由未证明能利用后缀绕过私有端点；空 body 登出保留已有幂等兼容行为。 |
| 07 | refresh 并发复用吊销遗漏、last_login 错误忽略、会话数量无界 | **并发缺陷已修复**。不能只补 RowsAffected==0 的 UPDATE；轮换和插入也必须串行。本轮事务内按用户行锁完成复核、消费、插入/复用吊销，并处理写错。现有全用户吊销策略保留；会话配额/独立家族设计属产品待办。 |
| 08 | goja 硬堆上限和缓存内存估计 | **有效风险，尚未完成容量验收**。超时/输出/栈限制不等于进程堆隔离；未运行危险 OOM 脚本或声称已有硬限制。进程隔离、并发容量与 pprof 评估列发布前待办。 |
| 09 | 域名/书源统一限流与 Cookie 责任边界 | **确认缺口，共享准入已补，其他边界仍待办**。按 domain-admission-design 与 source-admission-design 实现共享 hostname 与源 UUID 的 Redis/有界内存原子准入，覆盖数字并发、n/ms 令牌桶、响应租约、重试/重定向及 JS 身份继承；实际数据库验证五个服务入口，见 source-admission-verification-2026-11-14.md。Cookie 责任边界、混合旧版实例、暂停进程超过租约和远端忽略断连不在已完成保证内。 |
| 10 | 生产 JWT 允许弱短 key；Redis 错误泄漏 | **生产 key 强度已修复**，至少 32 字节；开发 fallback 行为保留。Redis AUTH/SELECT 已返回固定错误，连接地址诊断不等于密码泄漏；没有复现报告所称凭据泄漏。 |
| 11 | 32 MiB 导入超限返回 400 | **真实缺陷，已修复**。保留 MaxBytesError 类型并返回 413，拒绝尾部第二份 JSON/垃圾。无服务依赖测试实际构造超过边界的输入。 |
| 12 | 日志原始路径、缺 user_id、缺专名脱敏中间件 | **原始路径与认证用户关联已修复**。日志记录 chi 路由模板，未知路径固定 unmatched，认证上下文通过共享元数据传递；panic 不输出任意 panic 值/原始路径。没有必须取名 HttpLogSanitizer 才安全的要求。 |
| 13 | 单章覆盖没有试抓/预览、可写私网 URL 即 SSRF | **已登记功能缺口；SSRF 绕过未证实**。Service 校验所有权与 URL，实际出网仍走安全 Fetcher，存入 URL 不等于已访问内网。试抓、预览与写入一致性需作为模块交付，不能仅在 Handler 加一次网络请求。列待办。 |
| 14 | AddMapping/CacheBook 的坏 JSON 返回 422；替换规则创建/更新正则状态不同 | **坏 JSON 已修复为 400**。正则创建 422、更新 400 是各端点既有契约说明，不能为追求表面一致随意更改冻结行为。 |
| 15 | ExportSources 静默忽略非法 IDs / Encode 错误 | **公共路由非法 UUID 原已被生成绑定拒绝**。本轮进一步收紧 Handler 兜底分支，拒绝部分非法列表。响应写出失败后不能再补一份 JSON/重写状态；断连观测可另完善，非报告声称的任意成功导出漏洞。 |
| 16 | 多租户所有权和 RowsAffected 零行风险 | **未复现越权**。Progress/Mapping/Override/Job 调用链有 userID/书籍归属/事务锁，Repository SQL 约束租户。零行元数据更新可能是并发删除的无操作，不等于写到其他用户。全链真实并发/删除竞态仍可追加验收。 |
| 17 | sessionStorage 跨标签共享、续期无超时、auth 路由 401 不一致 | **共享说法错误；续期与 auth/me 问题已修复**。按 refresh token 分组共享任务，有界等待；结果未知不重放旧令牌，迟到响应不恢复旧会话；auth/me 可续期，login/refresh/logout 不盲重试。 |
| 18 | leave 网络阻塞、加载中写 0/旧正文残留 | **离开阻塞已修复**。先本机落盘，既有网络任务不阻塞导航；本机失败且仍有未同步位置时阻止丢失。初始无 base/加载中有 guard，正文错误界面本来隐藏旧内容；本轮另修“错误状态捕获隐藏旧正文偏移”，防止把位置写成章末。 |
| 19 | 502/503/504 不能离线回退 | **可用性缺口，已修复**。只允许网络与网关临时错误读匹配缓存；401/403/404 和续期未知不绕过。补网关恢复/403 拒绝及失败章节位置回归。 |
| 20 | getSession()! 四处可崩溃 | **可达性未证实，非已证实高危**。相关页面被登录路由守卫保护；直接把私有 composable 装入未登录测试不是当前公开入口。可作为防御性状态设计待办，不据此声称已绕过认证。 |
| 21 | 前端大 JSON 双份解析、书架无 override_count | **性能/展示待办**。文件读取前已有 32 MiB 限制，报告没有证明无限读入。32 MiB 同步解析确有主线程风险，需 Web Worker/分段的独立实现和测量；标记展示属 UX 待办。 |
| 22 | SourceEditor 无离开草稿保护 | **真实体验缺口，已修复**。已保存/未修改不询问；取消保留草稿，显式丢弃才离开；保存/删除成功更新基线。新增真实浏览器用例。 |
| 23 | 多设备、移动端与真实后端体验 | **验收待办**，未把 mock 浏览器回归冒充真机或真实多端验收。 |
| 24 | 标签页复制 refresh token 的轮换冲突 | **有效特定场景风险**。有 opener 时可能复制初始 sessionStorage，复制后仍各自隔离；并非持续共享。不能用广播敏感 token 草率修复，跨页会话策略需单独设计。 |
| 25 | 生成绑定绕过 Idempotency、必填数字缺失、负索引、If-Match | **混合结论**。中间件在 Handler 前校验 Idempotency，未复现生成器绕过。必填 chapter_index/version 缺失或 null 的确会退成零值，已收紧手写解码；补 int32 范围防截断；If-Match 收紧为契约引号正版本。负 override 索引原已拒绝，本轮另挡溢出。 |
| 26 | ErrorCode 开放 string、semver 声明与 lock 不同 | **误报/维护约束**。生成 string 类型不自动做运行期验证是工具行为，不等于漂移；代码已有枚举/映射测试。兼容范围内锁定更新不是缺陷，供应链扫描结果须实际执行，不能静态宣称无漏洞。 |
| 27 | M1c 历史三类语法缺口仍在 | **部分收口、其余待办**。!N 原来只剥离，现实际排除；表格片段与 JS 字面量/模板组合仍未全兼容。保留明确 unsupported 递归下降边界，没有声称通过所有真实站点。 |
| 28 | oapi-codegen YAML 与 go:generate 双入口 | **配置冗余风险，非当前漂移**。实际执行入口为固定版本 go:generate，独立 YAML 当前不被使用。可统一配置，但不能据未使用文件认定运行产物不同。列维护待办，未改生成代码。 |
| 29 | CAS 未先限尺寸、Close 锁次序危险、读时不看 ctx | **前两项不成立，取消检查已补**。原有 LimitReader 最大 1 MiB+1，读锁保护 Close，publication 锁次序一致。contextReader 仅能在 Read 边界合作取消，不能强制打断正阻塞的普通文件/NAS syscall。 |
| 30 | syncDir 失败没删中间目录，应回滚清理 | **误报且建议有风险**。ErrCommitUnknown 及保留目录是既定保全协议；删目录可能破坏并发操作或未知持久化现场。已存在父目录可重新核验，不一概视作后续重试必冲突。 |
| 31 | exactJSON 的 omitempty 空串/统一 ErrConfig 耦合 | **profile 的严格约束，非证明的 bug**。备份协议拒绝冗余空可选字段，统一错误避免带出密钥或路径。不存在要求任意 DTO 复用该解析器的通用契约，不为“通用性”放宽冻结格式。 |
| 32 | pg_restore 次数、预算、补丁 prologue | **性能/版本验收待办**。逐表选取不等于每次解压全部表；现有合成事务/取消验证不能证明大库预算充分。固定工具输出 fail-closed 是当前兼容 profile，不自动放宽可执行数据语法。 |
| 33 | guard 长持锁阻塞 Close/查询 | **现有单操作独占设计，不是已证实死锁**。未来 CLI 并发状态查询应读独立记录，不共享执行 guard。没有为提速破坏互斥和租约。 |
| 34 | NTP/同微秒导致状态更新拒绝 | **现有调用路径已处理**。advanceRecordedPhase 截断微秒并至少 old+1μs；外部构造不合规状态被拒绝是约束，不构成当前执行路径失败。 |
| 35 | S3、正式恢复入口、未知结果对账、A2 历史表 | **明确产品待办**。Linux 安全驱动其他平台 fail-closed、validating 无自动切流均符合当前范围；本轮不升级状态或 DROP 表。 |
| 36 | 审计资料完整性和“全仓读完” | **本地打包问题已修复，审计覆盖说法不可采信**。两份 go:embed 规范 txt 被过宽排除，现纳入；新增不切原文件的约 120 KB 文本分段。Gemini 承认后端 service/repository 与 backup 文档截断，不能同时称全仓已审完；不能仅靠无引用证明净室合规。 |

sessionStorage 的隔离与 opener 初始复制行为依据 [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)。其他结论以对应本地源码与测试为准，未照抄报告严重程度。
