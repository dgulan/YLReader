| 审计项 | 复核与处理 |
|---|---|
| 未提交、单副本 | 未提交属实，遵守本轮不提交约定。已有本地源码审计快照可辅助评审，但不能替代异机备份、Git提交与RC；“只有本机一份”未独立核实外部备份。 |
| LICENSE / README | README已补，链接设计、测试和发布限制。许可证待用户明确选择，不擅自赋予代码分发授权。 |
| worker / Compose / 固定口令 | 属实且仍为发布待办；保持worker显式opt-in，不用尚未验证的编排替换现有配置。 |
| Web安全基线 | API新增nosniff、DENY、no-referrer，含错误响应；Nginx新增CSP、nosniff、DENY、Referrer-Policy，并对精确登录路径按连接来源IP限制10次/分钟、burst5、返回429。不是跨实例/账户级限流，直连API不受该Nginx策略保护；API应留在受控内网。 |
| HSTS / token | HSTS需在实际HTTPS终止层配置，不给当前HTTP示例盲加。sessionStorage面临XSS读取风险，但存储位置本身不证明存在可利用XSS；HttpOnly迁移涉及认证/CSRF契约，未在本轮静默更换。 |
| Argon2 | 已限制PHC长度、版本、规范参数、迭代1–6、并行1–4、内存不超过128MiB、盐/输出尺寸，先拒绝再调用KDF，避免零参数panic及无界分配。当前生成参数不变，新增畸形参数回归通过。不是全服务并发认证内存硬上限。 |
| ARM | 原生运行门禁保留，模拟失败不计通过。 |
| 备份恢复 | “仅设计、未执行恢复”过于绝对。backup-http-verification记录了真实PostgreSQL归档恢复、对象发布、旧会话失效、新登录和阅读/进度/书签完整性验证；但明确scope为isolated-http-fixture，无公开恢复入口/生产切换授权。用户生产闭环仍待验收。 |
| 迁移 | migration-design及CLI已有版本账本、校验和、事务升级/锁和拒绝漂移能力；写入入口刻意只允许隔离库。缺的是生产升级流程及授权入口，不是完全缺少版本化引擎。不移除目标保护或添加自动down。 |
| 363kB chunk | 构建结果为dayjs相关CSS约363.29kB、gzip48.47kB，不能写成JS体积结论；管理样式按路由加载的生产专用测试需另验。 |
| 导入/配置/冻结 | 同步导入、沙箱运维参数入口、生产迁移、冻结评审等原待办保留。资源预算保持用户已完成的InflightBytes实现，不将系数估算当作Go堆硬上限；本轮不冒充复跑性能脚本。 |
| 超时时序测试 | 无限循环测试改为验证默认3秒策略、deadline事件、超时错误及后续执行恢复，移除依赖宿主调度精度的窄墙钟上界。生产超时未放宽，定向sandbox回归通过。 |
| 真实搜索 | 用户提供书源发现相对搜索URL未展开的真实缺陷，已按源基址解析并保留原Fetcher校验，新增Service回归及外部实测，详见第3阶段记录。 |
| 冻结漂移 | 对照上一轮审计快照，architecture仅增加在途预算行及错误映射说明；已补登记主冻结表。备份检查复用该主表，6份独立备份协议本身未漂移，未改写备份格式。摘要一致性恢复不代替人工评审。 |
