# 书籍信息管理交付（2026-11-13）

沿用 Frozen v1.5 修订 2 的 GET/PATCH/DELETE /books/{bookId}，不新增接口、DDL 或迁移版本。

## 行为和边界

书架卡片新增“管理书籍”。Element Plus 页面编辑书名、作者、连载状态和简介；提交加载时的 version，409 保留草稿并提示重新核对。重新加载和离开页面前确认未保存修改；简介使用空字符串清空。暂不提供封面、分组和批量操作。

删除需二次确认，明确关联阅读进度、书签等记录不可恢复；本地书提示清理服务端文件。沿用现有后端 StorageProvider 删除策略：数据库删除成功后尽力清理文件，文件清理失败记录日志，不保证同步清理完成。删除接口返回404视为另一端已完成；网络失败保留页面，允许显式重试。

保存后清理本账户该书的本机元数据和章节缓存，保留尚未同步的阅读位置。删除后清理该书本机元数据、章节、进度和最近任务跟踪记录；不会清理其他账户。服务端成功但本机清理失败时明确提示。跨设备离线副本、在途预取和后台任务不承诺即时取消或清理。退出、切书或卸载后忽略迟到响应。

后端修复重命名未同步 normalized_name/normalized_author 的缺陷，采用与加入书架相同的 textnorm 规则，避免去重仍命中旧书名。唯一键冲突映射为既有409；服务层拒绝空白书名和非法状态，规范书名/作者首尾空白。不更改书源映射名称和独立的阅读进度版本。
