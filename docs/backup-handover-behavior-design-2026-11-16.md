# 同次隔离 HTTP 行为与交接报告协议 v1

日期：2026-11-16。先行限定本轮范围：把既有真实路由 HTTP 隔离夹具的结果绑定同次 live guard / 八项报告，验证十项完整**隔离审阅报告**。本轮不提供面向真实用户的通用 HTTP 运行器、凭据采集 CLI、生产授权入口或状态 CAS，不部署或切换。

## 授权和旧凭据门禁

仅显式 isolated-http-fixture-v1 内部授权描述可使用本桥接，包含授权 UUID、1..8 个已有用户 UUID/用户名/密码和旧 access/refresh；不读取环境中的业务凭据、不修改恢复用户密码、不创建管理员。现有 fixture 在归档前设置合成账号，不能当作真实用户授权流程。本轮真实用户运行入口保持未交付。

在任何行为写入之前，检查旧 access 为源密钥签发的有效 HS256 JWT，exp 必填且当前有效、iat 必填且合法、Subject 匹配授权用户，tv 与恢复用户当前 token_version 恰差一。旧 refresh 必须匹配该用户归档会话、已撤销且尚未过期；用户启用、用户名及密码哈希验证匹配。请求结束后再次验证旧凭据，防止途中到期被误算为撤销。源/目标 JWT 密钥有界、不同，不输出或哈希进报告。错误统一脱敏；过期/伪造令牌的 401 不算撤销证据。

## 顺序与限定会话增量

先用真实身份/数据探测形成八项内存草稿，严格完成原 manifest 行数与会话撤销检查，暂不保存。随后复用真实 API HTTP 夹具：健康/readiness、旧令牌拒绝（包括源 JWT 配置下因版本变化拒绝）、新登录与刷新、用户/书架/目录/本地正文/进度/书签、跨用户拒绝、并发 refresh 重放保护、无 worker/外部抓取。临时 HTTP listener 仅在容器隔离回环，结束关闭；不是常驻启动。

跟踪本轮实际返回的全部新 refresh token，只通过这些 token 找到新会话 UUID，并用现有 Logout 撤销。不能通过“期间新增的所有行”猜测所有权，不删除会话、不修改 last_login_at 或倒退数据。新的已撤销会话行和正常 last_login_at 更新是明确授权的行为副作用，保留。

并发 refresh 的正常重放防护会按现有服务语义撤销该用户的全部活动会话；隔离 fixture 的前置检查及无用户流量保证这些均为本轮验证会话。此步骤不得迁移到有真实用户流量的目标；未知并发会话会导致最终核对失败，不能假定可回滚普通认证副作用。

私有行为凭据绑定 plan / 三份控制记录摘要 / publication 树、授权 UUID、用户集合、观察时间和本轮已知会话 UUID。原始 token、密码、正文不进入报告。凭据只能来自内部受信任 HTTP 夹具代码，不能反序列化外部 JSON；它不是自认证的生产执行授权。

关闭 HTTP listener 与连接池后，在同次仍持租约 guard 中重新核验对象/header/引用/安全状态。仅 auth_sessions 允许 manifest 原行数 + 已知 UUID 数（最多 32）；逐个核对唯一 UUID、所属授权用户、创建时间处于行为窗口、均已撤销。其他表行数仍严格匹配，所有会话均已撤销且无 queued/running 任务。不能宽泛忽略会话数、自动扩大差额或接纳未知会话；数据库与客户端时间偏差导致拒绝时不自动放宽。

## 报告终结与限制

草稿必须原本精确八项通过、JWT/runtime 两项 unavailable；身份/计划/时效仍有效，行为窗口在草稿完成后。完成后只将这两项改为 pass，保留原 expires_at、不续期，重验十项门禁再排他保存，ready_for_cutover/deployment_authorized 仍 false。已有八项文件不可覆盖，状态 CAS 仍未实现。

本轮完整报告 profile 只在合成隔离 fixture 验收，不能将测试账号/硬编码书籍断言充作通用生产核验器。行为失败或撤销确认失败不出成功证明，已产生的普通登录副作用不回滚、不自动重跑；暂不支持进程中断后的通用会话清理 CLI。源目标时点校验与协作租约仍不能防范恶意管理员或最后一次读后的变更。

## 验证

单测旧 JWT 的签名/算法/expiry/subject/version及私有凭据绑定、会话增量上限/去重、草稿状态与时间边界。扩展同一次 headerhttp 真实归档恢复，验证坏密码预检拒绝、八项草稿、授权预检、十项终结及排他保存；检查输出 operation/plan/package/manifest/publication 与本轮 HTTP 证据完全相同。保留原事务/header/发布故障回归，所有容器按本轮标签清理。
