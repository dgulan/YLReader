# 搜索与封面改造

沿用冻结的聚合搜索 JSON、现有书籍封面路径及备份契约。默认搜索遍历全部启用且有搜索规则的在线源，不套用管理列表分页上限。固定 worker 池与进程内共享并发槽限制出网量，单源预算在取得槽位后开始，客户端取消结束排队。每组按标题、作者相关性排序，组间按最佳命中、权重及稳定 ID 排序。显式 ID 保留现行验证。

动态 URL 通过既有沙箱执行，传入 key、page、baseUrl 和前置 URL。输出仍经 GET/POST 选项验证和全套抓取安全校验。中文旧编码用于模板参数的表单转义，也作为无明确响应媒体编码时的解码提示。既有字段解析器继续负责 CSS、XPath、JSONPath、正则和 JS。

列表与详情共用封面 URL 规范化。详情优先书源规则和元数据，再尝试标记封面、延迟加载图和首个可用图。书架经带 Bearer 的客户端请求同源封面、用对象 URL 显示并回收，搜索结果用已规范化的外链配合占位。代理保留归属校验，经过原有网络安全门禁，按二进制读取，限制容量和栅格类型，仅使用预期图片请求头。响应内容、认证信息和凭据不进入 URL。

## 实测与范围

- 指定临时参考目录在当前工作区不存在。对标使用仓库内已有的 `docs/research/givenge_reader-rust.md`，实现复用本项目解析器与抓取器。
- 合成 233 源覆盖 worker 并发限制、全量聚合和截取前排序。单测覆盖 POST 旧编码参数、两种动态 URL 语法、详情候选和图片二进制保真。前端回归验证实际封面请求带认证、图像失败后的占位和对象 URL 回收。
- 备份契约 65 项通过，16 份冻结摘要一致。后端普通全量测试通过，最后一次搜索解析调整后再次通过 service 包测试。前端 pnpm 类型检查、116 项测试及构建通过，依赖目录和锁文件的同步状态仍有 pnpm 警告。
- 原生 race 需要 gcc，当前 Windows 缺少该工具，Docker Linux 引擎未运行。固定端点使用聚合响应，整批耗时会随慢源数量增长。搜索预览仍由浏览器读取外链，要求防盗链 Referer 或只提供 HTTP 的图片可能显示占位。百源验证使用合成规则，实际线上命中率和图床兼容性还有待抽样。
