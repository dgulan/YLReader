# 阅读书签交付与验证

日期：2026-11-12。范围：M2 阅读器书签交互，沿用 Frozen v1.5 / API 1.0.0。

## 已交付

阅读器提供原生 dialog 书签面板，保存打开面板时捕获的章节、Unicode code point 偏移、正文起始 120 字摘录和备注。列表按章节与偏移排序，支持详情和跳转；删除先在面板内明确确认。长列表沿用虚拟滚动，少量记录按实际行数缩小高度。

创建/删除使用现有服务端接口。重复位置 409 不覆盖已有备注，保留未保存草稿；网络失败提示重试，失败删除保留记录；另一端已删除时 404 收敛为已删除。切书及卸载使旧请求失效，迟到响应不会写入其他书的状态。

跳转前经过现有阅读进度保存与冲突保护，读取目标正文后恢复字符偏移并保存新位置。书签没有源标识，换源后提示核对位置；章节索引超出当前目录时禁用跳转，不静默夹至其他章节。备注、摘录按纯文本渲染。

## 验证

- strict TypeScript 通过，23 项 Vitest 单测通过。新增 6 项覆盖 Unicode 摘录、位置与排序、409 保留原备注、删除失败和 404 收敛、切书/卸载后的迟到响应、列表失败重试。
- 生产镜像构建通过；最终生产 Nginx 上 6 项 Playwright 全部通过（28.4s）。既有登录、本地阅读与离线、搜索书架、虚拟目录、书源管理和换源回归均包含在内。
- 开发 Vite 上全量 6 项浏览器测试通过（23.9s），使用相同最终业务代码及修正后的测试就绪等待。
- 新书签场景使用真实隔离后端完成创建、重复拒绝、刷新后读取、跳转与删除；验证服务端保存的摘录与实际 Unicode 偏移一致。备注中的 script 字符串以文本显示，不执行。
- fixture 注入一次 503，验证草稿保留并可显式重试；125 条书签同时最多渲染 13 个按钮，失效章节禁止跳转。
- 390px 移动端无页面横向溢出；已检查 frontend/.test-artifacts/bookmarks-mobile.png。面板内容过长时内部滚动，沿用当前阅读主题。
- 新测试首次遗漏导航就绪等待，已补齐 URL 断言；后续一次在进度请求未完成时刷新，触发既有冲突保护，已将刷新恢复场景调整为先等待“进度已同步”。不放宽超时或跳过断言。
- 重复执行后既有导入测试所找的书源行移出虚拟列表首屏，已改为核对导入成功报告和后续真实 API 记录，不要求未渲染的行可见。

## 边界

本轮未修改后端及冻结的研究、架构、数据库或接口文件；10 个冻结文件摘要核验一致。未读取 references，未运行真实业务数据库迁移，没有提交、推送或触发远程 CI；前轮 race 数字不作为本轮新执行证据。

测试结束已移除本轮 yreader-proxyverify 的 4 个容器、专属网络与唯一测试卷。本地验证镜像和忽略目录内的截图保留，既有服务未停止。

书签需要联网；没有实现离线新增队列、备注修改或换源后自动重定位书签，这些不在现有接口交付范围。未保存备注关闭面板或刷新页面会丢失。整套阅读应用离线壳和真机性能验收仍未完成。
