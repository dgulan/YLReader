# 依赖安全整改设计（2026-11-13）

状态：本轮实施基线。用户已同意增量审查建议并授权继续；先登记设计再升级。Frozen v1.5修订2的43项API、数据库版本1、研究冻结摘要及迁移基线不变。

## 范围

1. 保存旧版本的完整Go source/symbol扫描和npm全锁审计结果；连接或解析失败不得计作通过。
2. Go最低工具链调整为官方支持分支的1.26.11补丁，CI与生产构建同步。工具包不加入应用模块。选择修复已确认公告的兼容依赖，不无差别全量latest；最终目标由扫描结果确定并记录前后版本。
3. JWT异常输入分配回归走真实认证解析入口；XPath真值布尔表达式放在可超时终止并Wait回收的独立测试子进程中，先验证旧版失败，再验证升级后通过；正常认证、规则、SSRF、导入和进度行为保持。
4. 新增独立安全CI：固定官方govulncheck版本，扫描Linux生产目标及完整npm锁文件；使用原生非JSON扫描退出码阻止漏洞发布，原始日志始终保留。应用升级前后扫描不以JSON模式exit0作为安全结论。
5. 后端基础镜像迁移到常规支持中的Alpine分支；生产镜像OS门扫描最终产物，扫描器失败也阻止通过。前端构建与运行镜像同样纳入门禁。未实际构建/扫描的镜像不得称已验收。

## 不变与验证

保留JWT HS256、通用401、token_version、刷新轮换；不放弃XPath、不以黑名单代替底层修复，不复制参考实现。依赖升级不改DDL或引入CGO。普通Go全包、integration vet、隔离数据库全量集成、前端类型/单测/构建及浏览器回归验证兼容性。没有本机C工具链时不宣称执行Windows race；远程CI和实际双架构镜像验证结果另列。

下载工具链校验官方归档SHA256；本机使用项目.toolchain目录，不替换系统Go。数据库验证仅使用已有55439专用集群及随机测试库。
