# 动作账本只读命令契约

本协议先于代码接线，复用已验收DiagnoseBehaviorLedger，不修改API/DDL、账本格式或旧status输出。

命令为 `backup behavior-status --control-root ABS --operation UUID [--format json|text]`。与status共享严格参数校验、安全私有控制目录打开与5秒上下文；只读取固定控制/动作槽，不读取配置、凭据、归档或环境连接信息，不连接数据库/Redis/HTTP，不接受DSN、重试、修复或清理参数。Windows安全文件驱动不支持时返回3，不降级。

默认输出现有BehaviorLedgerDiagnostic JSON。text展示状态/原因、dispatch/known/logout响应计数，并明确“数据库撤销：未核验；历史持久确认：无法推断；允许派发/重试/部署：否”。输出前必须确认安全目录Close成功；打开/关闭/输出错误只用固定文本，不回显私有路径或底层错误。

退出码：0仅responses_observed（全部响应声明完整，不是数据库撤销或执行授权）；2参数错误；3安全目录/平台不可用；4输出需要人工核对的诊断（含缺记录/未知/陈旧/矛盾/变化/不可用）；5关闭或输出失败。不得用0驱动恢复、服务切换或再次登录。

操作员先确认正确operation及原始控制区，保留意向/dispatch/response/logout；未知或确认丢失不删除、不补写、不覆盖或重试。无known不证明未执行，完整logout响应不证明已撤销，当前revoked也不能补造历史确认。数据库复核仍是独立的内部显式身份核验接口，本命令不接通它。单独导出的日志或报告不是控制区。

验证新增CLI参数/格式/关闭/错误与注意状态，并在无网络Linux独立进程中覆盖完整/缺失/父记录未确认/矛盾/陈旧及链接、权限拒绝；对照内容与权限不变，并回归旧status命令。不重跑无改动的完整数据库恢复链冒充本轮新增证据。
