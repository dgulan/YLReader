## 已实现

- 登录、tab 会话保存、access 续期并发合并、失败退出；退出清除该用户离线记录，迟到的续期不能复活已退出会话。
- Legado JSON 预检及确认导入、书源虚拟表格；搜索按源展示结果与部分失败，加入书架。
- 分页书架、名称/作者筛选、TXT/EPUB 文件导入入口；保留服务端警告与哈希去重语义。
- 书籍信息管理：书名、作者、连载状态和简介，版本冲突保留草稿；确认删除及按账户/书籍清理本机记录。
- 原生 DOM 阅读器，日间/夜间/羊皮纸/护眼主题、字号、前后章、原生对话框与虚拟目录。章节正文以文本显示，不执行导入 HTML。
- 使用 Unicode code point 字符偏移保存、恢复；保存串行使用服务端最新版本；另一端更新时显式选择本机或远端。未解决冲突刷新后保留原始版本，不自动覆盖远端。
- Dexie 缓存当前章及前后各两章，按用户及活跃源/书籍版本隔离；网络中断才回退章节缓存。未同步进度留在 IndexedDB，联网/再次打开时重试，有版本冲突仍需确认。

## 运行与测试

前端目录执行 `npm ci`、`npm run dev`；默认 API 代理 localhost:8080。可通过 VITE_API_TARGET 指向自己的开发后端。编排前端与开发服务器默认端口均为 5173，同时运行时为开发服务器指定其他端口。

`npm run type-check` / `npm test` / `npm run build` 可独立运行。`npm run generate:api` 从冻结契约重建类型，生成文件需随变更提交。Makefile 提供对应入口。

端到端测试必须使用隔离后端：提供 E2E_USERNAME/E2E_PASSWORD，默认后端 127.0.0.1:55808，或设 E2E_API_TARGET；Windows 使用独立 Edge，Linux 使用 Playwright Chromium。若 E2E_BASE_URL 指定现有生产构建测试地址，则不启动 Vite。测试会创建书籍/书源，不得对真实用户环境执行。缺少凭据时本机测试跳过，CI 则明确报错。

新增 .github/workflows/frontend.yml 包含类型同步、类型检查、单测、构建及真实测试后端浏览器流程。YAML 和凭据初始化脚本已本地验证；没有推送或触发 GitHub Actions，不声称远端已通过。
