# 单书后台缓存任务交付与验证

日期：2026-11-13。范围：按 Frozen v1.5 既有任务接口补齐前端入口、提交和状态跟踪。

## 行为

- 在线书架卡片提供后台缓存入口，页面采用 Element Plus；本地书说明无需网络缓存，不提供提交操作。
- 目标源限定已绑定映射，使用虚拟选择器；读取目标目录后指定包含首尾的章节范围。界面从 1 开始，提交转换为从 0 开始；空目录、非整数、反向和越界范围不提交。
- 通过既有 POST /books/{id}/cache 提交，GET /jobs/{id} 读取，DELETE /jobs/{id} 取消。明确标示服务端预热不会把整本下载到浏览器。
- 本机每个账户、每本书保存最近一次任务。IndexedDB 第 4 版增量新增 jobs 表，不删除既有章节、阅读进度或设置；退出清理该账户本机任务记录，不取消服务端任务。
- 在途任务每 2 秒读取状态，终态和卸载停止；读取失败保留旧状态并暂停，允许手动刷新。切书或账户变化后忽略迟到响应。
- 取消需要明确确认，之后读取服务端状态；若已推进到终态而返回 409，则读取最新结果。404 标为记录不可用，不伪造已取消状态。
- 请求提交失败不自动重试。网络断开时结果可能未知，重试可能收到已有任务提示；不会声称严格幂等。

## 验证

- strict TypeScript 通过；38 项 Vitest 单测通过。新增 7 项覆盖章节转换/校验、记录保存与恢复、自动刷新/停止、取消时终态竞争、网络失败重试、切书迟到响应与账户清理、任务不存在的处理。
- 原有 IndexedDB 旧版升级测试继续通过，包含原阅读位置保留；新任务结果对象可持久化并重新读取。
- 生产 Node 22 / Nginx 镜像构建通过；开发 Vite 上全量 8 项 Playwright 通过（54.2s），包括既有书签、阅读离线与进度、搜索书架、虚拟目录、设置、书源管理和换源。
- 相同最终业务代码在生产 Nginx 上全量 8 项浏览器测试通过（33.9s）。
- 任务专项真实调用隔离后端完成 202 提交、章节参数检查、状态读取、刷新恢复、取消及取消确认撤回。目录夹具只写入隔离库；章节 URL 为安全过滤器拒绝的回环地址，真实 Worker 进入失败状态，不请求公网。
- 为稳定验证取消，等待真实 Worker 失败后，仅将本测试拥有的任务行设为带未来租约的受控 running 检查点，再通过真实取消接口核对 canceled。这不是慢速公网抓取中断或完整预热成功验收。
- 仅对任务 GET 注入断网，验证错误提示、暂停刷新和显式恢复。390px 页面截图已检查，无横向溢出，位于 frontend/.test-artifacts/cache-task-mobile.png。
- 初次轮询单测使用的伪时钟阻塞 IndexedDB 调度，已改为真实轮询及定时器清理断言。未增加测试超时或跳过断言。

## 边界

当前只跟踪本设备为本书提交的最近任务，不提供全账户历史或其他设备任务发现；现有契约没有任务列表接口。提交回执丢失时也无法据此查出未知编号。重新登录或清理本机数据后不能恢复已删除的本机任务记录。

服务端缓存有自己的有效期，成功不代表永久保存或浏览器整本离线。浏览器仍沿用当前章及邻章缓存；完整离线应用壳仍未实现。没有新增任务类型或修改 Worker 行为。

本轮未修改后端和冻结契约；10 个冻结摘要核验一致。未访问 references，未迁移真实业务库，未提交、推送或发布，也未触发远端 CI；本轮不声称重新运行 Go race。

验收后已清理本轮 yreader-proxyverify 的 4 个容器、专属网络和唯一测试卷。本地验证镜像和忽略目录中的截图保留，现有业务服务未停止。
