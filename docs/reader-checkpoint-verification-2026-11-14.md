# 阅读进度检查点验收（2026-11-14）

本轮按 [检查点约定](reader-checkpoint-design-2026-11-14.md) 完成前端进度保存边界修复。API、If-Match 乐观锁、进度冲突处理及 IndexedDB 结构保持兼容；没有部署、提交、推送或合并，备份恢复仍处于 validating。

## 行为变化

- 页面进入 hidden 或收到 pagehide 时，清除 600ms 滚动 debounce、捕获位置，并立即尝试本机检查点与版本化同步。已有慢 PUT 时，最新本机位置单独写入，不等待该网络请求；不会因为共享网络任务而跳过本机检查点。
- 同时触发的保存共享一个 Promise，等待者获得同一个成功或失败结果，不在失败后各自递归重试。任务内部继续用 revision 合并新位置：旧请求确认后，更新版本，再提交期间新增的位置。
- 保存固定书籍及世代，并在异步边界复核会话用户；旧确认/错误不能跨新视图更新状态。已发出的服务端写入仍可能提交，不宣称取消 UI 就回滚了远端结果。
- 服务器确认与本机确认分开处理。服务端已成功但本机写入失败时保留已确认版本，明确提示本机记录待更新；位置不再变化的本机重试不会重复 PUT。若请求期间又产生新位置，提示区分上次确认与仍待保存的新位置。
- 本机写入失败时，不再使用“已保存在本机”的离线提示。dirty 状态使用“进度等待同步”，避免尚未落盘时提前声称本机保存成功。
- 409 继续保留本机位置和原始版本，重载后仍须显式选择；没有自动覆盖远端。

## 验证结果

- strict 类型检查及生产构建通过；最终构建日志 `.toolchain/reader-checkpoint-build.log`。
- 13 个测试文件、66 项单测通过，日志 `.toolchain/reader-checkpoint-vitest.log`。新增 single-flight 失败共用/显式重试、同步抛错释放任务、生命周期可见性判断及监听清理测试。
- 最终生产静态预览 Edge：11 项通过、0 失败/跳过/重试；结果 `.toolchain/reader-checkpoint-playwright.json`。包含此前六项加载/目录/布局/资源回归，以及本轮五项进度场景。
- 场景一：滚动后注入 hidden/pagehide，网络断开时保留非零字符位置及 dirty、原始版本 7；重载仍保留该位置，显式 online 后服务器与本机同步为版本 8。
- 场景二：首个 PUT 被挂起时再次滚动并隐藏，本机立即保留更新的位置、dirty 和原版本 7；首个请求释放后仅按 If-Match 7→8 连续提交两次，最终本机基线为 9，服务器位置等于最新位置。
- 场景三：409 后重载，本机基线仍为 7、远端为 8；用户选择远端才切到对应章节并标记本机干净，没有额外 PUT。
- 场景四：只让版本 8 及以后的本机记录写入抛出合成 QuotaExceededError。服务器已是版本 8，界面提示本机记录失败；恢复存储后点击保存，本机更新为干净的版本 8，PUT 总数仍为一次。
- 场景五：所有本机位置写入失败且网络断开，明确显示“当前离线，且本机记录未保存”，不显示已本机保存；原有本机位置与远端版本不被伪造为新值。
- 65 项契约检查、16 份冻结摘要匹配；diff 格式检查通过，没有新增依赖。

## 测试隔离及复现

增加 `frontend/tests/preview.config.ts`，显式使用空 preview.proxy，禁止继承开发服务的 /api 代理；阅读器测试结束前先退出视图，确保生命周期处理器在 mock 撤销前卸载。首次检查时曾在关闭测试页面后发现合成进度请求触发默认开发代理，连接日志为 ECONNREFUSED；最终配置下重新执行全部 11 项，预览 stderr 为零字节。测试主体 API 全部拦截，没有使用真实凭据或业务数据库。

在 frontend 构建后，启动：

```powershell
npm run preview -- --config tests/preview.config.ts --host 127.0.0.1 --port 55175 --strictPort
```

另一终端设置 E2E_BASE_URL=http://127.0.0.1:55175、E2E_PRODUCTION=1，再运行 `npm run test:e2e -- tests/modern-web.spec.ts tests/reader-loading.spec.ts`。预览配置只用于静态合成验收，不改变正常开发代理或生产部署配置。

hidden/pagehide 是测试主动注入的 DOM 事件；IndexedDB、渲染、路由及版本请求链使用真实浏览器。它不证明操作系统挂起、强制关闭、断电或移动端杀进程时一定完成异步保存，也不覆盖真实后端的 COMMIT 确认丢失。本轮未重跑需真实后端的历史集成场景、真机或跨浏览器验收。
