# 书架封面与阅读浮层

参考项目用紧凑的图文卡片、惰性图片、固定裁切区域和失败占位。服务端按用户保存封面，并使用图源域名作为 Referer。YLReader 延续自身的书架结构和认证代理，采用 3:4 封面和按用户隔离的内存对象 URL 缓存。相同书籍及封面共用请求，代理失败再试原图。确认封面变更或删除时释放旧资源。

阅读正文容器使用固定视口尺寸与始终保留的底部余量，工具栏、设置和状态通知移出正文布局。章末状态根据实际滚动距离计算，并在章节与布局变化时更新。冻结 API、数据库及备份契约继续适用。

本地验证通过备份契约 65 项及 16 份冻结文件摘要、Go 全量测试、前端类型检查和生产构建。前端 116 项测试通过，包含封面认证、跨挂载复用、外链回退与回收。Playwright 开发模式 3 项通过，生产预览 4 项通过，覆盖正文坐标、章末导航及阅读路由加载的 CSS。前端使用现有依赖目录，pnpm 报告其与锁文件不同步。本轮图片回归使用合成响应。
