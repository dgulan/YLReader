# 阅读器加载优化验收（2026-11-14）

依据 [加载与取消约定](reader-loading-design-2026-11-14.md)，本轮完成请求归属、取消边界、预加载调度和 Unicode 定位优化。未修改后端、冻结接口、数据库或 IndexedDB 版本，未增加依赖，未部署、提交、推送或合并。此前备份恢复仍保持 validating。

## 实现结果

- loadChapter 在任何 await 前固定 owner/bookId/context/index/signal；即使调用者的对象随后改变，缓存仍写原请求的键。网络、缓存读取/写入后检查取消，取消不进入离线降级、不报告虚假的缓存故障。已开始的 IndexedDB 操作不能回滚，未声称撤销其已完成写入。
- boot 为元数据使用独立控制器；书籍、目录、进度请求可传入可选 AbortSignal。离开、换书或重新启动时取消旧加载，在异步边界校验后才更新当前视图和位置。旧章节的 finally 不再把新加载误标为完成，取消的翻章不登记新进度。
- API 请求层在开始、响应、错误响应 JSON 和成功 JSON 的边界检查信号，避免已取消的晚到 401 启动续期或清空当前会话。共享续期本身仍由认证层管理，不将一个读取请求的取消扩散为所有用户请求取消。
- 正文展示后按下一章、上一章、后两章、前两章预加载，最多两个并发。单个邻章失败不替换正文；取消后不启动排队任务。仍保留五章 IndexedDB 窗口及网络失败时读取匹配书源版本缓存的行为，没有默认复用可能过期的在线正文。
- codePointLength 扫描 UTF-16，合并有效代理对，保持未配对代理项边界行为；utf16Offset 遍历所需前缀，不再创建整章字符数组及切片/拼接数组。既有 WeakMap DOM 偏移索引、二分可见位置查找、服务端码点计数语义保持。

## 实测与验证

使用本机 Node 26.13.0、700,000 码点的中英/emoji 合成正文，先预热，再取 7 次中位数。脚本读取并转译实际 position.ts，不运行另一份替代实现；旧函数仅作为比较基线。原始结果 `.toolchain/reader-position-benchmark.json` 含源码摘要。

| 操作 | 修改前中位数 | 修改后中位数 |
|---|---:|---:|
| 整章码点计数 | 5.4203 ms | 1.7678 ms |
| 第 128 码点的 UTF-16 定位 | 5.4933 ms | 0.0142 ms |
| 第 650,000 码点的 UTF-16 定位 | 19.8801 ms | 4.6147 ms |

这是本地函数微基准，不是浏览器 INP、内存峰值、真机续航或完整翻页时间。复现：在 frontend 运行 `node scripts/benchmark-position.mjs`；具体数字随设备和运行负载变化，不作为固定 CI 时间阈值。

- strict 类型检查通过；12 个测试文件、63 项单测通过，日志 `.toolchain/reader-loading-vitest.log`。新增 11 项覆盖取消后晚到响应、不可变缓存键、离线分支、存储失败、双并发、队列取消、旧 401 取消及 Unicode 边界。
- 最终生产预览 Edge 共 6 项通过，0 失败/跳过/重试；日志 `.toolchain/reader-loading-playwright.json`。
- 新增真实浏览器场景：A 的元数据被故意挂起，离开并打开 B 后释放 A；确认浏览器触发 A 请求失败/取消，B 正文和缓存未被 A 覆盖。两个邻章挂起时只启动两个请求，离开后其余两个不再启动，缓存只保留已完成的当前章。五章缓存完成后模拟全 API 断网，仍可打开下一章并显示离线缓存。
- 上一轮三项浏览器场景一并回归：千章目录键盘/焦点、小屏与横屏、生产阅读器不加载管理 CSS。全部 API 是合成拦截，没有真实用户令牌、数据库或书源请求；临时预览仅绑定 127.0.0.1，结束关闭。
- 生产构建通过，日志 `.toolchain/reader-loading-build.log`。入口 CSS 仍为 5.82 KB，阅读器 CSS 7.64 KB；本轮增加少量请求调度 JS，不声称 JS 包体积下降。
- 65 项契约检查、16 份冻结摘要及 diff 格式检查通过。

浏览器复现沿用上一轮生产预览方式，设置 E2E_BASE_URL 和 E2E_PRODUCTION=1 后执行 `npm run test:e2e -- tests/modern-web.spec.ts tests/reader-loading.spec.ts`。本轮没有重跑需真实后端的历史浏览器场景，也没有做 Firefox、Safari、移动真机或服务端压力验收。
